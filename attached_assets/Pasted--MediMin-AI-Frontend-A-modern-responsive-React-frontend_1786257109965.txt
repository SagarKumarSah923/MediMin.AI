# MediMin-AI Frontend

A modern, responsive React frontend for the MediMin-AI medical assistant platform. This application provides an intuitive interface for users to interact with AI-powered health analysis, symptom checking, and medical guidance.

## Features

- 🏥 **AI-Powered Health Analysis** - Advanced symptom analysis and health insights
- 💬 **Interactive Chatbot** - Real-time AI medical assistant
- 📊 **Health Dashboard** - Comprehensive health tracking and analytics
- 📝 **Health Assessment Forms** - Detailed health data collection
- 📱 **Responsive Design** - Works seamlessly on all devices
- 🔒 **Secure & Private** - HIPAA-compliant data handling
- 🎨 **Modern UI/UX** - Beautiful, intuitive interface

## Tech Stack

- **React 18** - Modern React with hooks and functional components
- **React Router** - Client-side routing
- **Axios** - HTTP client for API communication
- **Lucide React** - Beautiful, customizable icons
- **Framer Motion** - Smooth animations and transitions
- **CSS3** - Custom styling with modern CSS features

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd MediMin-AI/frontend
```

2. Install dependencies:
```bash
npm install
```

3. Create environment file:
```bash
cp .env.example .env.local
```

4. Configure environment variables:
```env
REACT_APP_API_URL=http://localhost:8000/api
REACT_APP_ENVIRONMENT=development
```

5. Start the development server:
```bash
npm start
```

The application will be available at `http://localhost:3000`

## Key Components

### Navbar
Responsive navigation with mobile menu, user authentication, and smooth scrolling.

### Chatbot
AI-powered medical assistant with real-time chat interface, typing indicators, and message history.

### HealthForm
Comprehensive health assessment form with validation, progress tracking, and data submission.

### Dashboard
User dashboard with health metrics, recent assessments, reminders, and personalized insights.

## API Integration

The frontend integrates with the backend API through the `utils/api.js` service layer:

- **Authentication** - User login, registration, and profile management
- **Health Data** - CRUD operations for health assessments and data
- **AI Services** - Symptom analysis, chat functionality, and recommendations
- **Reports** - Health report generation and download
